Task formulation & reward design

01 · REINFORCEMENT LEARNING

手内旋转：任务建模与奖励函数

目标是在 XHand 1 Pro 上学习连续圆柱旋转策略。每次重置对手、物体和奖励旋转轴施加同一组均匀 SO(3) 变换，使策略覆盖相对于重力方向的不同手部朝向；任务并非离散目标姿态跟踪。

OBSERVATION 141 D

最近 3 帧 ×（21 维归一化关节角 + 21 维关节目标 + 5 维指尖法向触觉）。

ACTION 21 D

策略输出经裁剪后，以 1 / 24 的尺度累加到上一时刻关节目标，并受真实关节限位约束。

CONTROL 20 Hz

物理步长 1 / 240 s、decimation = 12；仿真采用与真机一致的显式 PD 力矩形式。

TERMINATION 2.5 cm

在手坐标系中计算物体相对标称抓取位姿的偏移，超过阈值即判定掉落并终止回合。

REWARD AT CONTROL STEP t 最终乘以 Δt = 0.05 s
rt = Δt [ 2.5 rω − 0.3 plin − 0.4 pq − 0.1 pτ − 0.5 pwork + 0.003 rpos ]
rω

物体角速度在目标旋转轴上的投影，裁剪至 [−0.5, 0.5] rad/s。

plin

物体平移速度的 L1 范数，抑制以平移或甩动换取角速度。

pq

当前关节角相对标称抓取姿态的平方偏差。

pτ

21 个关节力矩的平方和，用于限制控制幅值。

pwork

总机械功率 τᵀq̇ 的平方，约束高频能量注入。

rpos

物体位置误差倒数 1 / (‖p − p₀‖₂ + 0.001)。

02 / 02

Policy learning & sim-to-real

TEACHER–STUDENT · DOMAIN RANDOMIZATION · DEPLOYMENT

从仿真策略训练到 XHand 真机控制

训练采用 privileged teacher 与 deployable student 的两阶段结构。仿真随机化用于覆盖模型参数不确定性，部署阶段则保持观测定义、关节顺序、控制频率和力矩控制律一致。

01 · TEACHER

PPO 特权策略

策略网络为 512–256–128 MLP；训练时额外接收物体位移、摩擦、质量、质心和尺度构成的 9 维特权信息。云端训练规模为 20,480 个并行环境。

02 · STUDENT

ProprioAdapt 蒸馏

冻结 teacher，由 TConv 编码 30 × 47 的本体—触觉历史并估计 9 维特权隐状态；部署时不读取物体真值或仿真参数。

03 · MODEL SELECTION

多条件定量评估

在真实重力和多摩擦条件下比较多个训练种子，联合考察掉落率、有向角速度、反转率与动作抖动，而非依据训练回报单指标选择权重。

02 · GENERATIVE CONTROL

DexGen：基于关键点运动表征的生成式控制

系统不直接生成关节控制量，而是先预测具有几何意义的关键点运动，再由逆动力学模型映射为关节控制目标。RL 专家轨迹、MANUS 指令与执行反馈因而能够在统一的运动表征下进行建模。

OFFLINE TRAINING PIPELINE

数据采集、监督构造与分阶段训练

在线执行顺序是 Diffusion → IDM；离线训练时先用 oracle motion 验证 IDM，再训练 Diffusion，以便将“运动生成误差”和“关节映射误差”分离。

  1. 01COLLECT

    冻结 RL 专家并采集 CW / CCW rollout

    在 IsaacLab 的 full-DR 与 SO(3) 条件下运行冻结的 ProprioAdapt 专家，分别采集稳定旋转和主动扰动后的恢复轨迹。扰动阶段不作为动作监督，只保留随后由干净专家产生的恢复动作。

    输入CW / CCW RL checkpoint、环境 seed、扰动配置 记录关节状态、绝对 PD target、关键点、触觉、物体状态、终止与恢复标签
  2. 02WINDOW

    构造统一的状态—运动—控制监督

    利用 XHand 精确 FK，将五个 PIP 与五个真实指尖胶垫转换到腕坐标系。按 episode 划分训练集与验证集，裁除失败尾部并建立时序窗口，避免跨 episode 泄漏。

    state history [4, 83] future motion [2, 10, 3] next PD target [21]
    83D state15D 指尖位置 + 21D 关节角 + 21D 当前 target + 21D 控制误差 + 5D 触觉 motion相对当前关键点的 0.1 / 0.2 s 腕坐标系位移
  3. 03IDM

    训练 IDM：关键点运动到关节控制目标

    IDM 接收状态历史与 oracle future motion，通过 residual MLP 回归 RL 专家在下一规划时刻达到的 21 维绝对 PD target；主损失为 target MSE，触觉分支使用加权的 future-touch Smooth L1 辅助损失。

    监督(state history, oracle motion) → next absolute PD target 验收在验证集检查 oracle-motion → IDM 的 target MAE / RMSE

    术语：IDM 指 Inverse Dynamics Model。它学习运动表征到闭环关节目标的映射，不等同于仅依据末端位姿求关节角的传统几何逆运动学。

  4. 04DIFFUSION

    训练条件扩散模型：生成未来关键点运动

    以 4 帧状态历史、旋转模式和扩散时间步为条件，对归一化后的两帧关键点 motion 加噪并预测 ε。正式配置采用 cosine noise schedule 与 100 个训练扩散步，触觉 v2b 分支同时预测未来触觉。

    训练目标ε-prediction MSE + 0.005 × future-touch auxiliary loss 推理DDIM 采样，线上默认 25 steps；guidance 在物理 motion 空间施加
  5. 05VALIDATE

    离线串联评估与 Isaac 闭环验证

    先分别测量 Diffusion motion 误差和 oracle-motion → IDM 误差，再检查 Diffusion → IDM 的 target 误差；最终在 Isaac 中以多 seed 和固定 exposure 评估掉落率、有向转速、反向旋转比例及 generated → executed tracking。

ENGINEERING REFLECTION

工程方法与研究结论

01

数据契约是跨域部署的前提

状态维度、关节顺序、触觉掩码、坐标系和时间语义需要随 checkpoint 固化并校验；否则观测语义偏差会直接影响 sim-to-real 结果。

02

闭环指标优先于单一离线损失

motion MAE 仅用于基本回归验证；部署效果还需结合掉落频率、有向转速、反向旋转比例、扰动恢复率及 generated→executed tracking 误差进行评估。

03

安全约束属于控制系统设计

HOLD、输入超时、温度保护、关节限幅、预抓取和急停需要纳入统一状态机，确保策略输出满足真实硬件的运行约束。

04

实验结论需要可复现与可证伪

结构对比采用多个随机种子和一致的样本预算；未超过基线的实验同样保留配置、指标与结论，以支持后续复核。

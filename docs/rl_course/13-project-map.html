零、读代码之前

如果你「完全看不懂」仓库里的 Python，先别慌——本章不要求你立刻能写代码，只要知道名词对应什么文件夹、一条命令会经过谁。下面 8 个词会在后面章节反复出现，先混个脸熟。

本章术语速查（先背下来，细节后面章节会讲）

import（导入）
像在说「请把另一个文件里的工具拿过来用」。例如 import torch 才能用 PyTorch。副作用 import 指：导入时顺便执行注册代码（如 gym.register），你并没显式调用函数。
模块 / 包（module / package）
一个 .py 文件是一个模块；一个带 __init__.py 的文件夹是一个包。本项目训练代码主要在包 rl_isaaclab 里。
class（类）
一种「蓝图」。例如 XhandWaveInhandRotateEnv 是仿真环境的蓝图；gym.make(...) 会按蓝图造出真正跑仿真的对象（实例）。
cfg / 配置（configuration）
一堆可调参数的集合：episode 多长、重力多大、动作有几维……写在 xhand_wave_env_cfg.py 或 ppo_cfg.yaml 里，而不是散落在代码各处。
dict（字典）
Python 的键值对容器，写法 {"gamma": 0.99}。YAML 读进来通常是 dict；用方括号取键：agent_cfg["seed"]。
tensor（张量）
PyTorch 里的多维数组，常在 GPU 上。形状 (10, 21) 可理解为：10 个并行环境，每个 21 个数（动作）。
gym / Gymnasium
强化学习界的「标准插座」：reset() 开局、step(action) 走一步。任务名如 Isaac-Inhand-Rotate-Xhand-Wave-v0 要先 register 登记，gym.make 才能创建。
CLI（命令行参数）
你在终端里跟在命令后面的 --num_envs 10、--headless 等。它们会覆盖配置文件里的默认值。
把读代码想成逛商场：你不需要第一天就学会装修（写环境类），只要知道「生鲜区在哪、收银台在哪、会员卡（配置）怎么用」。本章就是商场导览图；第 14 章带你走一次收银全流程（train.py）。
你可能会问：我连 Python 基础都没有，能跟这门课吗？
可以。Part B（13–22 章）按「先认路 → 再跟脚本 → 再拆配置」设计。遇到不懂的 Python 语法，先记下这行在整条流水线里干什么，语法可以边用边补。建议同时开一个Python 官方教程当字典。
你可能会问：era_dexhand_lab 和 rl_isaaclab 是什么关系？
era_dexhand_lab 是整个项目文件夹（含资产、文档、缓存）。rl_isaaclab 是其中的Python 代码包，pip install -e . 之后可在任意目录 import rl_isaaclab。

一、仓库目录树

把整个项目想成一家「教机械手转笔」的工厂：仿真车间（Isaac Sim）里成千上万只虚拟手同时练习；算法办公室（PPO）记录谁转得好并改策略；练成的「大脑」存成 .pth；最后真机装配线（deploy_xhand）把大脑接到真实 Xhand 手上。

二、pip install -e . 之后发生了什么

在项目根目录执行 pip install -e . 后，Python 可以 import rl_isaaclab。包名在 pyproject.toml 里是 sharpawave-rl-lab，但 import 路径是 rl_isaaclab.*。

pip install -e . 里的 -e 表示「可编辑安装」：你改仓库里的代码，不用重新 pip，下次运行立刻生效。就像把书架的书登记到你名下，但书仍放在原项目文件夹里。

训练脚本里有一行关键 import：

train.py · 副作用 import 
import rl_isaaclab.tasks.inhand_rotate  # 触发 gym.register(...)
副作用 import · 逐词解释
代码白话解释
import rl_isaaclab.tasks.inhand_rotate加载 tasks/inhand_rotate/__init__.py 这个文件，并执行文件里顶层的所有语句。
（文件内）gym.register(id=..., ...)向 Gymnasium 登记：任务名叫啥、对应哪个环境类、配置从哪读。
之后 gym.make("Isaac-Inhand-Rotate-Xhand-Wave-v0")查登记表，找到 XhandWaveInhandRotateEnv 并创建仿真实例。

这行不调用任何函数，但会执行 tasks/inhand_rotate/__init__.py，把 Isaac-Inhand-Rotate-Xhand-Wave-v0 等任务注册到 Gymnasium。之后 gym.make("Isaac-Inhand-Rotate-Xhand-Wave-v0") 才知道该实例化哪个类。

你可能会问：为什么不把 gym.register 写在 train.py 里？
可以，但集中写在 __init__.py 更省事：只要 import 一次任务包，所有变体（训练 / 抓取 / Sharpa）都登记好。任何脚本（train / play / gen_grasp）import 同一行即可。

三、零基础 Python 补课（最小集）

下面四块是读 Part B 的最低 Python 门槛。每块后面都有 walk-table；看不懂某一行时，先对照表格里的白话，再回来看代码。

1. dict 与 @configclass

算法配置是 YAML 读进来的 dict，例如 agent_cfg["algorithm"]["gamma"]。环境配置是 IsaacLab 的 @configclass dataclass，字段用点号访问：env_cfg.action_space。

dict vs configclass · 两种取配置的方式
写法示例白话解释
agent_cfg["seed"]从字典里用键 "seed" 取值，像查通讯录：键是名字，值是号码。
agent_cfg["algorithm"]["gamma"]嵌套字典：先找到 algorithm 这一块，再取里面的 gamma（折扣因子）。
env_cfg.action_spacedataclass 用点号访问字段，像对象的属性：env_cfg 的 action_space 是 21。
env_cfg.scene.num_envs字段里还可以嵌套别的配置对象，继续用点号往下点。
你可能会问：为什么算法用 dict、环境用 dataclass，不统一？
历史原因：PPO 配置来自 YAML（天然是 dict）；IsaacLab 生态习惯用 @configclass 做类型提示和默认值。训练时 ConfigWrapper 把两者捆在一起交给算法（见第 15 章）。

2. torch.Tensor 与 shape

本项目大量用 PyTorch 张量。记法 (num_envs, dim)：第一维是并行环境数（如 10），第二维是特征维（如动作 21）。例如观测 obs.shape == (10, 186)。

把 (10, 21) 想成表格：10 行 = 10 只虚拟手同时练，21 列 = 每只手本步要调的 21 个关节增量。GPU 一次算整张表，所以比「for 循环 10 次」快得多。
shape 常见例子
shape白话解释
(10, 21)10 个环境，每个 21 维动作。
(10, 186)10 个环境，每个 186 维观测（关节+触觉+历史等拼在一起）。
(10,)10 个标量，常见是 10 个环境的 reward 或 done 标志。
.device张量在 CPU 还是 GPU；训练时通常 cuda:0。

3. gym.make 是什么

Gymnasium 标准接口：env.reset() 返回初始观测；env.step(action) 返回 obs, reward, done, info。本项目用 IsaacLab 的 DirectRLEnv 实现，再经 GymStyleEnvWrapper 适配 PPO。

gym 环境 · 四个必会方法
调用白话解释
env = gym.make(task_id, cfg=env_cfg)按任务名造环境；cfg 把配置灌进去（并行数、重力等）。
obs = env.reset()新开一局：手复位、物体重新抓起，返回「第一帧传感器读数」。
obs, r, done, info = env.step(action)执行一帧动作；返回新观测、奖励、是否结束、额外信息。
env.close()释放仿真资源；train.py 结尾会调。

4. eval(algo) 动态创建类

train.py 
agent = eval(agent_cfg["algo"])(env, output_dir=log_dir, full_config=config)
# algo 字符串 "PPO" → PPO(...) ； "ProprioAdapt" → ProprioAdapt(...)
eval 一行拆成三步（初学者版）
步骤白话解释
agent_cfg["algo"] 得到 "PPO"从配置里读出要用哪个算法，是字符串不是类本身。
eval("PPO") → 名字 PPO 对应的类把字符串当成 Python 名字解析；所以文件开头必须先 from ... import PPO。
PPO(env, output_dir=..., full_config=...)调用类的构造函数，造出真正的训练器对象，赋给变量 agent。

eval 把字符串当成 Python 表达式执行。这里 agent_cfg["algo"] 只能是已 import 的类名（PPO 或 ProprioAdapt）。

你可能会问：eval 很危险吗？
在通用编程里，对用户输入用 eval 确实危险。这里字符串只来自你自己的 YAML/CLI（PPO 或 ProprioAdapt），且类已白名单 import，属于项目内约定写法。

你可能会问：.pth 是什么？
PyTorch 保存的模型权重文件（神经网络参数 + 有时还有归一化统计）。训练越久，logs/ 里会积累 last.pth（最新）和 best.pth（验证最好）等。部署和 play 都要指定 --load_path 指向其中一个。

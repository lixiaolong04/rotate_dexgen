一、端到端五步

① 生成抓取缓存 gen_grasp（一次性，5–10 分钟）

先让手"抓稳"物体，把一批合法的初始抓握姿态存成缓存。之后每局重置都从缓存里随机取一个起手式，省去每次重新抓的成本。

python rl_isaaclab/scripts/gen_grasp.py \
  --task Isaac-Inhand-Rotate-Grasp-Xhand-Wave-v0 --headless

② Stage 1：PPO 训练教师（第 05 章）

用特权信息 + PPO 训出会转物体的教师策略。RTX 5070 Ti 12GB 上 --num_envs 10 是安全起步（真正大规模训练会用上万环境）。产物是 stage1_nn/ 下的 best/last 检查点。

python rl_isaaclab/scripts/train.py \
  --task Isaac-Inhand-Rotate-Xhand-Wave-v0 --headless --num_envs 10

③ Stage 2：蒸馏学生（第 06 章）

冻结教师，只训 TConv，让学生从历史估计隐变量。开课程时推荐用 last.pth。产物是 stage2_nn/。

python rl_isaaclab/scripts/train.py \
  --task Isaac-Inhand-Rotate-Xhand-Wave-v0 --headless \
  --algorithm ProprioAdapt --load_path <stage1 last.pth>

④ 可视化策略 play

开 GUI 看策略表现，确认转得对不对、稳不稳。

python rl_isaaclab/scripts/play.py \
  --task Isaac-Inhand-Rotate-Xhand-Wave-v0 --num_envs 16 \
  --load_path ckpts/<训练目录>/best.pth

⑤ 真机部署 deploy

丢掉特权信息，只用 obs+历史→TConv→主干→动作（第 06 章）。键盘控制：e 开始 / w 冻结 / q 回零位。

python rl_isaaclab/scripts/deploy.py \
  --task Isaac-Inhand-Rotate-Deploy-... --hand_side 0/1 --load_path <pth>

四、入口怎么把零件拼起来

这是理解工程结构的关键一段——train.py 用 Hydra 读配置，建环境、套封装、按 --algorithm 选 PPO 或 ProprioAdapt：

scripts/train.py（节选） 
env = gym.make(args_cli.task, cfg=env_cfg, render_mode=None)     # 建 IsaacLab 环境
env = GymStyleEnvWrapper(env, clip_actions=env_cfg.clip_actions) # 套成"上万环境并行"的接口
agent = eval(agent_cfg["algo"])(env, output_dir=log_dir, full_config=config)  # PPO 或 ProprioAdapt
if args_cli.resume or agent_cfg["algo"] == "ProprioAdapt":
    agent.restore_train(resume_path)   # 蒸馏要先加载教师权重
agent.train()
串起九章。 GymStyleEnvWrapper 把环境包成统一接口（动作裁剪、obs/priv_info/proprio_hist 字典、time_outs 处理）；PPO/ProprioAdapt 内部各自组装 ActorCritic（含 TConv，第 07 章）、RunningMeanStd（第 08 章）、ExperienceBuffer（GAE，第 04 章）。环境侧 xhand_wave_env.py 负责观测/奖励/域随机化（第 02、09 章）。

六、九章回顾：一条逻辑线

MDP（01） 定义了"在状态里选动作拿奖励"的框架 → 本项目（02） 把它实例化成 21 维动作、186 维观测、六项奖励 → 动作来自 高斯策略（03），由 σ 控制探索 → 用 GAE（04） 估计"这步多好" → PPO（05） 用裁剪目标稳稳更新教师 → 教师靠特权信息，于是用 RMA 蒸馏（06） 训出能上真机的学生 → 学生的眼睛是 TConv（07），整网由 ActorCritic 搭成 → 全程靠 归一化（08） 稳定数值、靠 域随机化（09） 跨越现实落差 → 最终（10）串成端到端管线，部署到真机。

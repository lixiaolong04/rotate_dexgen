CHAPTER 04 · 这一步到底好不好

广义优势估计 GAE

奖励常常姗姗来迟。GAE 用一个旋钮 λ，在"看一步"与"看到底"之间优雅地平滑过渡。

一、信用分配难题

你下了一盘棋，第 40 步赢了。可真正的好棋也许是第 12 步埋的伏笔。奖励来得晚，怎么知道该表扬哪一步？ 这叫"信用分配（credit assignment）"问题。
第 01 章我们定义了优势 $A=Q-V$："这一步比平均好多少"。但 $Q$ 和 $V$ 我们都不知道真值，只能估计。GAE 就是一种又准又稳的优势估计法。

二、积木：TD 误差 δ

回忆第 01 章的贝尔曼递归 $V(s_t)=r_t+\gamma V(s_{t+1})$。如果我们的价值估计 $V$ 完全准确，这个等式应当成立。两边之差就是时序差分误差（TD error）：

$$\delta_t \;=\; \underbrace{r_t + \gamma\, V(s_{t+1})}_{\text{基于真实奖励的"新证据"}} \;-\; \underbrace{V(s_t)}_{\text{原本的预期}}.$$
符号表 · TD 误差
符号含义
$\delta_t$第 $t$ 步的"惊喜值"。>0 = 比预期好，<0 = 比预期差。
$r_t$第 $t$ 步真实拿到的即时奖励。
$V(s_t)$Critic 对当前状态价值的估计。
$\gamma V(s_{t+1})$折扣后的下一状态价值估计，作为"未来"的代理。

$\delta_t$ 本身就是优势的一个一步估计——它只用了一步真实奖励，其余全靠 $V$ 来"脑补"。准，但短视。

三、两个极端：蒙特卡洛 vs 一步 TD

方法用多少真实奖励偏差 bias方差 variance
一步 TD（只用 δ_t）1 步高（严重依赖可能不准的 V）低（只含一步随机性）
蒙特卡洛（用到回合结束）全部低（几乎不靠 V）高（累积了所有步的随机性）
一步 TD 像"只看眼前一步就下判断"——稳，但容易被不准的预估带偏（偏差大）。蒙特卡洛像"等到尘埃落定再算总账"——不偏，但运气成分太重，每次差很多（方差大）。我们想要中间地带，GAE 给的正是一个连续可调的中间地带。

四、GAE：把不同步长的估计指数加权

GAE 的思想：把"看 1 步、看 2 步、看 3 步……"的各种估计，用一个衰减系数 $\lambda$ 加权平均。最终结论惊人地简洁——它等于未来所有 TD 误差的 $(\gamma\lambda)$ 指数加权和：

$$\boxed{\;\hat A_t^{\text{GAE}} \;=\; \sum_{l=0}^{\infty} (\gamma\lambda)^{l}\,\delta_{t+l} \;=\; \delta_t + (\gamma\lambda)\delta_{t+1} + (\gamma\lambda)^2\delta_{t+2} + \cdots\;}$$
符号表 · GAE
符号含义
$\hat A_t$第 $t$ 步优势的 GAE 估计。
$\lambda\in[0,1]$GAE 的核心旋钮（代码里叫 tau，本项目 = 0.95）。
$\gamma$折扣因子（0.99）。注意权重是 $\gamma$ 和 $\lambda$ 的乘积。
$l$向未来看的步数偏移。

两个极端一眼可见：

  • $\lambda = 0$：只剩 $\hat A_t = \delta_t$ → 退化成一步 TD（低方差、高偏差）。
  • $\lambda = 1$：$\hat A_t = \sum_l \gamma^l \delta_{t+l}$，望远镜拉满 → 等价于蒙特卡洛（低偏差、高方差）。

本项目取 $\lambda=0.95$：偏向蒙特卡洛但仍压住方差，是实践中的黄金默认值。

从级数到递归（代码就靠这一步）

无穷级数没法直接算，但它有个漂亮的递归结构。把第一项拆出来：

$$\hat A_t = \delta_t + (\gamma\lambda)\big[\delta_{t+1} + (\gamma\lambda)\delta_{t+2}+\cdots\big] = \delta_t + \gamma\lambda\,\hat A_{t+1}.$$

于是只要从最后一步往前倒推，一遍就能算完所有 $\hat A_t$。这正是代码里 computer_return 的 reversed(range(...))：

experience.py · computer_return（GAE 反向递推） 
last_gae_lam = 0
for t in reversed(range(self.transitions_per_env)):
    next_values = last_values if t == T-1 else self.storage_dict['values'][t+1]
    next_nonterminal = 1.0 - self.storage_dict['dones'].float()[t]   # 终止则截断未来
    delta = rewards[t] + gamma * next_values * next_nonterminal - values[t]
    mb_advs[t] = last_gae_lam = delta + gamma * tau * next_nonterminal * last_gae_lam
    returns[t] = mb_advs[t] + values[t]      # 回报 = 优势 + 价值基线
那个 next_nonterminal 是什么？ 它在回合正常结束（物体掉了）时 = 0，把"未来"一刀切断——因为掉了之后就没有未来价值可言了。这保证 GAE 不会跨越回合边界错误地"借用"下一局的奖励。

五、回报、价值基线与优势标准化

有了优势，顺手就得到 Critic 的回归目标——回报（return）：

$$\hat R_t \;=\; \hat A_t + V(s_t).$$

Critic 之后会被训练去拟合 $\hat R_t$（见第 05 章的价值损失）。

最后一步是把整批优势标准化（减均值、除标准差），让数值落在 0 附近、尺度统一，使梯度更新更稳：

$$\tilde A \;=\; \frac{\hat A - \operatorname{mean}(\hat A)}{\operatorname{std}(\hat A) + 10^{-8}}.$$
experience.py · prepare_training 
advantages = self.data_dict['returns'] - self.data_dict['values']
self.data_dict['advantages'] = (advantages - advantages.mean()) / (advantages.std() + 1e-8)

加 $10^{-8}$ 防止除以零。标准化后，"比平均好"的动作优势为正、"比平均差"的为负，天然契合 PPO"好动作加概率、坏动作减概率"的逻辑。

六、超时不是失败：value bootstrap

一局到了 20 秒时间上限被强制结束，但这时手可能转得正欢——这是"下课铃响了"，不是"做错了"。如果直接当作终止，会冤枉这个本来很好的状态。

解决办法：对"超时"（time_out，而非真摔了）的那一步，把折扣后的价值估计补回奖励里，相当于告诉算法"后面其实还有价值，只是被下课打断了"：

ppo.py · play_steps 
shaped_rewards = 0.01 * rewards.clone()
if self.value_bootstrap and 'time_outs' in infos:
    shaped_rewards += self.gamma * res_dict['values'] * infos['time_outs'].unsqueeze(1).float()

（那个 0.01 是奖励缩放，把奖励整体调到适合学习的数量级。）

本章小结。 TD 误差 δ 是积木，GAE 用 $(\gamma\lambda)^l$ 把它们加权成优势 $\hat A$；λ 在偏差与方差之间平滑调节（本项目 0.95）。反向递推一遍算完，回报 = 优势 + 价值，优势再标准化。万事俱备——下一章 PPO 终于要用这个优势来真正更新策略了。

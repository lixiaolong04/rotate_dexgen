CHAPTER 03 · 策略的形状

高斯策略、对数概率与熵

连续动作怎么做到"随机探索但又听话"？答案是一个钟形曲线，以及它的对数和熵。

一、为什么动作要"带随机"

学骑车不能只走一条死路线，得东倒西歪地试，才能发现"原来稍微往左压一点更稳"。如果策略每次都输出一模一样的动作，它永远发现不了更好的做法——这叫探索不足。
办法是：网络不直接输出一个动作，而是输出一个钟形概率分布，真正执行时从里面随机抽一个。分布越"胖"，探索越大胆；越"瘦"，越倾向于走已知最优。

对离散动作（比如上下左右）可以用 softmax 给每个动作一个概率。但我们的动作是 21 个连续的关节增量，连续空间的自然选择是高斯分布（正态分布）。

二、对角高斯策略

本项目策略是一个对角协方差高斯分布：网络输出 21 维均值 $\mu$，再配一个 21 维标准差 $\sigma$，各维相互独立：

$$\pi_\theta(a\mid s) \;=\; \mathcal{N}\!\big(a;\; \mu_\theta(s),\; \operatorname{diag}(\sigma^2)\big) \;=\; \prod_{i=1}^{21} \frac{1}{\sqrt{2\pi}\,\sigma_i}\, \exp\!\left(-\frac{(a_i-\mu_i)^2}{2\sigma_i^2}\right).$$
符号表 · 高斯策略
符号含义（含代码对应）
$\mu_\theta(s)$动作均值，21 维，由 Actor 网络根据状态算出。代码 mu = self.mu(x)。
$\sigma_i$第 $i$ 维标准差（探索幅度）。代码 sigma = torch.exp(logstd)。
$\operatorname{diag}(\sigma^2)$对角协方差矩阵：各维独立，无相关性，所以能写成连乘。
$a_i$实际采样到的第 $i$ 维动作。
$\sqrt{2\pi}\,\sigma_i$高斯密度的归一化常数，保证概率积分为 1。

一个关键细节：σ 是"全局可学习参数"

注意看代码——$\sigma$ 不是网络根据状态算出来的，而是一个独立于状态的可学习向量：

models.py · ActorCritic.__init__ / _actor_critic 
self.sigma = nn.Parameter(torch.zeros(actions_num))   # 21 维，初始为 0
# ...
nn.init.constant_(self.sigma, 0)                      # 初始 logσ=0 → σ=exp(0)=1
# 前向时：
return mu, mu*0 + sigma, value, ...                   # logstd 与状态无关，对所有 s 相同
为什么这样设计？ 探索幅度通常不需要因状态而异，做成一个全局参数更稳定、更省参数。训练初期 $\sigma=1$（探索大胆），随着学习推进，梯度会自动把 $\sigma$ 降下来（探索收窄、趋于确定）。代码里存的是 $\log\sigma$ 而非 $\sigma$，这样无论参数取什么实数，$\sigma=e^{\log\sigma}$ 永远为正，且对小值更敏感。

三、对数概率与 neglogp（推导）

PPO 训练时需要"某个动作出现的概率"。直接用概率会因连乘而数值下溢，所以一律用对数概率。对上面的连乘取对数，乘变加：

$$\log \pi_\theta(a\mid s) \;=\; \sum_{i=1}^{21}\left[\, -\tfrac{1}{2}\log(2\pi)\;-\;\log\sigma_i\;-\;\frac{(a_i-\mu_i)^2}{2\sigma_i^2}\,\right].$$

逐项解释这三块（这是数学专业读者最该盯住的地方）：

  • $-\tfrac12\log(2\pi)$：常数项，来自归一化系数里的 $\frac{1}{\sqrt{2\pi}}$ 取对数。
  • $-\log\sigma_i$：来自归一化系数里的 $\frac{1}{\sigma_i}$。$\sigma$ 越大，密度峰值越矮，对数概率越小。
  • $-\frac{(a_i-\mu_i)^2}{2\sigma_i^2}$：核心项。动作 $a_i$ 离均值 $\mu_i$ 越远，惩罚越大（二次衰减）。

代码里用的是它的相反数 neglogp（negative log probability），因为优化器习惯"最小化损失"：

models.py · act 
distr = torch.distributions.Normal(mu, sigma)
selected_action = distr.sample()                          # 从分布里随机抽动作
neglogpacs = -distr.log_prob(selected_action).sum(1)      # 对 21 维求和 = log 连乘

.sum(1) 对应公式里的 $\sum_{i=1}^{21}$——因为各维独立，联合对数概率 = 各维对数概率之和。

四、熵：探索的"温度计"

熵（entropy）衡量一个分布的"不确定性/混乱度"。高斯分布越胖，熵越大。对角高斯的熵有解析式：

$$\mathcal{H}\big[\pi_\theta(\cdot\mid s)\big] \;=\; \sum_{i=1}^{21} \tfrac{1}{2}\log\!\big(2\pi e\,\sigma_i^2\big) \;=\; \sum_{i=1}^{21}\left[\,\tfrac12 + \tfrac12\log(2\pi) + \log\sigma_i\,\right].$$

注意它只依赖 $\sigma$，与 $\mu$ 无关，并且随 $\log\sigma_i$ 线性增长。PPO 的损失里会加一个"熵奖励"鼓励高熵（即鼓励探索），防止策略过早变得死板。

models.py · forward 
entropy = distr.entropy().sum(dim=-1)   # 21 维熵相加；之后在 PPO 损失里以 entropy_coef 加权
本项目的有趣设定。 PPO 配置里 entropy_coef = 0.0，即没有显式熵奖励。探索完全交给"$\sigma$ 这个可学习参数 + 大量并行环境的天然多样性"来提供。这在大规模并行（上万个环境）的灵巧手任务里是常见且有效的选择。

五、采样 vs 推理：训练随机、部署确定

阶段用什么代码
训练采样从分布随机抽 $a\sim\mathcal N(\mu,\sigma)$，保留探索act() → distr.sample()
测试/部署直接用均值 $a=\mu$，最确定、最稳act_inference() → 只返回 mu
练车时大胆试错（采样），考试和上路时就走最稳的那条线（取均值）。同一个钟形分布，训练取"随机一抽"，部署取"正中心"。

六、动手感受：σ 如何掌管探索

高斯采样动画 · 探索 vs 利用
蓝色钟形是策略分布 N(μ, σ)，竖线是均值 μ。点"采样一次"会抽出一个动作（小竖标）。拖动 σ 感受分布变胖/变瘦。
熵随 σ 的变化
单维高斯的熵 = ½·log(2πe σ²)。红点是当前 σ 对应的熵——可见 σ 越大，熵越高（越鼓励探索）。
本章小结。 策略 = 对角高斯 $\mathcal N(\mu_\theta(s),\sigma)$；$\mu$ 由网络给、$\sigma$ 是全局可学习的探索旋钮。对数概率把连乘变连加，是 PPO 计算"概率比"的原料；熵是探索的温度计。下一章我们要回答另一个核心问题：怎么判断"刚抽到的这个动作，到底好不好"——这就是优势估计 GAE。

网络与 ProprioAdapt

ActorCritic 如何把 186 维观测变成 21 维动作？Stage 2 如何冻结教师、只训 TConv？本章对照 models.py、running_mean_std.py、padapt.py，衔接06、07、08三章原理。

两阶段共用一套 ActorCritic 类。 差别只在构造参数 proprio_adapt：Stage 1（PPO）为 False，走 env_mlp(priv_info)；Stage 2（ProprioAdapt）为 True，走 adapt_tconv(proprio_hist)。主干 MLP、Actor 头、Critic 头结构相同。

本章术语表

ActorCritic
策略网络（Actor 输出动作 μ）+ 价值网络（Critic 输出 V）合体类。共享前半段特征提取。
env_mlp
把 8 维 priv_info 编码成 8 维隐变量 z 的小 MLP。Stage 1 训练；Stage 2 冻结，只当 label。
adapt_tconv（ProprioAdaptTConv）
时序卷积网络：输入 (N,30,62) 历史 → 输出 (N,8) 估计 ẑ。Stage 2 唯一训练的模块。
extrin / z / ẑ
拼到 obs 后面的 8 维「环境上下文」向量。z=教师真值（priv_info 来）；ẑ=学生猜测（历史来）。
requires_grad=False
冻结参数：forward 还算，backward 不更新。Stage 2 除 adapt_tconv 外全部冻结。
strict=False
load checkpoint 时允许缺少键。Stage 1 ckpt 无 adapt_tconv 权重，随机初始化后开训。
sa_mean_std
对 proprio_hist (30×62) 逐元素在线归一化。Stage 2 训练更新，部署 eval 冻结。
act vs act_inference
前者高斯采样（训练探索）；后者只返回 μ（部署/蒸馏控手）。

零、把神经网络想成「大脑分区」

ActorCritic 不是一团黑箱，可以按脑区理解：
• 感觉皮层 — running_mean_std：把 raw 观测归一化到网络熟悉的尺度。
• 海马体 / 小抄区 — env_mlp(priv_info)：Stage 1 直接读「上帝小抄」z；真机没有这区。
• 工作记忆区 — adapt_tconv(proprio_hist)：Stage 2 从 30 帧历史猜小抄 ẑ，替代 env_mlp。
• 运动皮层 — actor_mlp → mu：综合 obs+z 后输出 21 维关节指令。
• 评估区 — value head：估计「这状态有多好」，仅 Stage 1 PPO 训练用。
• 噪声发生器 — 可学习 sigma：训练时加探索，部署时不用。

Stage 2 蒸馏 = 只练工作记忆区（adapt_tconv），其他脑区全部冻结，继续用 Stage 1 练好的运动皮层转笔。
问：为什么 Stage 2 叫「只练小抄模块」？ env_mlp 读的是仿真 priv_info（质量、摩擦等），真机没有。TConv 的任务是只看 proprio 历史，输出与 env_mlp 尽量一样的 8 个数，让冻结的 actor_mlp「以为」小抄还在——这就是 RMA 蒸馏的核心。

一、ActorCritic 总览

可以把 ActorCritic 想成"两条入口汇一条河"：观测 obs 始终进入；第二条入口要么是上帝小抄 z（特权编码），要么是学生猜的 ẑ（历史编码）。拼在一起后，一条 MLP 河分出两个出口：Actor 输出动作均值 μ，Critic 输出标量价值 V。
models.py · __init__（结构） 
class ActorCritic(nn.Module):
    def __init__(self, kwargs):
        actions_num = kwargs.pop('actions_num')       # 21
        input_shape = kwargs.pop('input_shape')       # (186,)
        self.units = kwargs.pop('actor_units')        # [512, 256, 128]
        self.priv_mlp = kwargs.pop('priv_mlp_units')  # [256, 128, 8]
        self.priv_info = kwargs['priv_info']
        self.priv_info_stage2 = kwargs['proprio_adapt']

        if self.priv_info:
            self.env_mlp = MLP(self.priv_mlp, input_size=priv_info_dim)  # 8→8
            if self.priv_info_stage2:
                self.adapt_tconv = ProprioAdaptTConv(input_shape[0] // 3)  # 62 维单帧

        self.actor_mlp = MLP(self.units, input_size=186 + 8)  # 194 维进主干
        self.value = nn.Linear(out_size, 1)
        self.mu = nn.Linear(out_size, actions_num)
        self.sigma = nn.Parameter(torch.zeros(actions_num))   # 全局可学习 log-std

四、ProprioAdaptTConv

结构详解见第 07 章。

models.py · ProprioAdaptTConv 
class ProprioAdaptTConv(nn.Module):
    def __init__(self, frame_shape):          # Xhand: frame_shape = 186//3 = 62
        self.channel_transform = nn.Sequential(  # 逐帧 MLP
            nn.Linear(frame_shape, frame_shape), nn.ReLU(),
            nn.Linear(frame_shape, frame_shape), nn.ReLU())
        self.temporal_aggregation = nn.Sequential(
            nn.Conv1d(frame_shape, frame_shape, 9, stride=2),  # 30 → 11
            nn.ReLU(),
            nn.Conv1d(frame_shape, frame_shape, 5, stride=1),  # 11 → 7
            nn.ReLU(),
            nn.Conv1d(frame_shape, frame_shape, 5, stride=1),  # 7 → 3
            nn.ReLU())
        self.low_dim_proj = nn.Linear(frame_shape * 3, 8)      # 62×3 → 8

    def forward(self, x):                     # x: (N, 30, 62)
        x = self.channel_transform(x)
        x = x.permute(0, 2, 1)                # (N, 62, 30)
        x = self.temporal_aggregation(x)      # (N, 62, 3)
        return self.low_dim_proj(x.flatten(1))
ProprioAdaptTConv.forward · 逐行
代码白话
channel_transform(x)对每一帧 62 维向量做相同 MLP，提取帧内特征。
permute(0, 2, 1)(N,30,62) → (N,62,30)：Conv1d 把 62 当 channel、30 当时间轴。
Conv1d k=9,s=2时间维 30 → 11。看约 9 帧窗口，步长 2 下采样。
Conv1d k=5,s=1 ×211 → 7 → 3。三层卷积把 1.5 秒历史压成 3 个时间 bin。
low_dim_proj(flatten)62×3=186 → 8。输出 ẑ，与 env_mlp 的 z 同维。
30 帧历史 ≈ 1.5 秒的手感记忆（仿真 20Hz × 30）。TConv 用三层卷积把"这段时间手被物体推成什么样"压成 8 个数——正好与教师的 $z$ 同维，方便做 MSE。

五、RunningMeanStd 在线归一化

running_mean_std.py · forward() 
def forward(self, input, unnorm=False):
    if self.training:
        mean = input.mean(self.axis)
        var = input.var(self.axis)
        self.running_mean, self.running_var, self.count = \
            self._update_mean_var_count_from_moments(...)

    if unnorm:    # 价值反归一化
        y = sqrt(var + eps) * clamp(input) + mean
    else:
        y = (input - mean) / sqrt(var + eps)
        y = clamp(y, min=-5.0, max=5.0)
    return y

六、ProprioAdapt：冻结教师 + MSE 蒸馏

6.1 加载教师并冻结 — 「只练小抄模块」

6.2 训练循环：MSE + 用 μ 控环境

padapt.py · train() 
while self.agent_steps <= 1e9:
    input_dict = {
        'obs': self.running_mean_std(obs_dict['obs']).detach(),
        'priv_info': obs_dict['priv_info'],
        'proprio_hist': self.sa_mean_std(obs_dict['proprio_hist'].detach()),
    }
    mu, _, _, e, e_gt = self.model._actor_critic(input_dict)
    loss = ((e - e_gt.detach()) ** 2).mean()    # ★ MSE(ẑ, z)
    self.optim.zero_grad()
    loss.backward()
    self.optim.step()

    mu = torch.clamp(mu.detach(), -1.0, 1.0)
    obs_dict, r, done, info = self.env.step(mu)   # 用教师 μ 驱动仿真
padapt.train() 每步 · 逐行
代码白话
running_mean_std(obs).detach()obs 归一化，detach 不传梯度到 RMS（RMS 在 Stage 2 冻结 eval）。
sa_mean_std(proprio_hist)历史归一化，train 模式会更新 sa_mean_std 统计量。
_actor_critic(...)返回 mu、V、extrin(ẑ)、extrin_gt(z)。
MSE(e, e_gt.detach())让学生 ẑ 逼近教师 z。e_gt detach 防止梯度流向 env_mlp。
loss.backward(); optim.step()只有 adapt_tconv + sa_mean_std 有梯度（后者若 insize 大可训练 buffer）。
env.step(mu)用冻结 Actor 的 μ 控手，保证数据分布与 Stage 1 相近。奖励只监控，不进 loss。
Stage 2 不是 RL：没有 PPO、没有 GAE。每一步只做回归——让 TConv 输出逼近 env_mlp 输出。环境仍用冻结的主干+Actor 算出的 μ 去转物体，保证数据分布与 Stage 1 相近。奖励只用于监控 best.pth，不进 loss。

八、MLP 辅助类

models.py · MLP 
class MLP(nn.Module):
    def __init__(self, units, input_size):
        layers = []
        for output_size in units:
            layers.append(nn.Linear(input_size, output_size))
            layers.append(nn.ELU())
            input_size = output_size
        self.mlp = nn.Sequential(*layers)
MLP · 逐行
代码白话
for output_size in units按列表堆 Linear 层，如 [512,256,128]。
nn.ELU()激活函数。ELU 负半轴平滑，利于连续控制（比 ReLU 少 dead neuron）。
无残差简单堆叠，与 RMA 论文原版一致。

十、forward() 更新阶段详解

models.py · forward() 
def forward(self, input_dict):
    prev_actions = input_dict.get('prev_actions', None)
    mu, logstd, value, extrin, extrin_gt = self._actor_critic(input_dict)
    sigma = torch.exp(logstd)
    distr = torch.distributions.Normal(mu, sigma)
    entropy = distr.entropy().sum(dim=-1)
    prev_neglogp = -distr.log_prob(prev_actions).sum(1)
    return {'prev_neglogp': ..., 'values': value, 'entropy': entropy, ...}
forward · 与 act 的区别
点act()forward()
动作来源从分布采样新动作用 buffer 里已存的 prev_actions
目的探索、收集轨迹算新策略对旧动作的 log prob → PPO ratio
探索有随机性无采样，确定性 eval 旧动作概率
entropy不返回返回，用于 entropy bonus

十一、sigma 初始化与 bounds loss

ActorCritic.__init__ 末尾 nn.init.constant_(self.sigma, 0)，即初始 log-std=0 → σ=1。PPO 的 bounds loss（bounds_loss_coef > 0 时）惩罚 μ 超出 soft_bound=1.1，防止动作长期顶在饱和区。

bounds loss · 代码含义
代码白话
clamp_max(mu - 1.1, 0) ** 2μ 超过 +1.1 的部分平方惩罚
clamp_max(-mu + 1.1, 0) ** 2μ 低于 -1.1 的部分平方惩罚
sum(axis=-1)21 维动作分别惩罚后求和

十四、FAQ

问：Stage 2 为什么还要 env.step(mu)？ 需要新数据：物体位置、域随机化、接触状态每步都在变，TConv 必须在各种手感下学猜 z。μ 来自冻结 Actor，转动物体的行为与 Stage 1 一致。
问：蒸馏时 gravity 为什么要 -9.81？ train.py 在 ProprioAdapt 分支强制真实重力（见源码注释）。Stage 1 可能用 gravity curriculum 近失重；Stage 2 要在真机条件下蒸馏，否则 student 学的是「假重力」下的历史模式。

域随机化与重力课程

为什么训练时要"故意把仿真搞乱"？因为只有见过千百种世界的策略，才不会在真实世界里水土不服。

一、现实落差与域随机化

仿真再逼真，也和真机有差距：真实物体可能更重、摩擦更大、电机更软、还有你没建模的空气阻力。如果只在"一个完美仿真世界"里训练，策略会把这个世界的细节背得死死的，一上真机就懵。
域随机化（Domain Randomization）反其道而行：每一局都把物理参数随机抖一抖——这次物体重一点、下次滑一点、电机硬一点。策略被迫学会"不管世界什么样都能转好"的通用本领。真机不过是它见过的千万种世界里的普通一种。
与第 06 章的呼应。 这些被随机化的物理量（质量、摩擦、质心……）正是教师的特权信息 priv_info！训练时代码把随机出来的值写进 priv_info_buf，喂给 env_mlp 编码成隐变量 z。所以"域随机化"和"RMA"是一对：前者制造多样世界，后者让学生学会从历史认出自己身处哪种世界。

三、PD 增益的"双峰采样"技巧

重置时随机缩放每个关节的 $k_p,k_d$。但代码没有简单地从 $U(0.5,2)$ 采样，而是用了一个巧妙的双峰方案：

xhand_wave_env.py · _rand_pd_scales 
rand_scale_s = Uniform(lower, 1).sample(...)   # 在 [0.5, 1] 取一个"变软"
rand_scale_l = Uniform(1, upper).sample(...)   # 在 [1, 2]   取一个"变硬"
mask = rand() > 0.5
rand_scale = where(mask, rand_scale_s, rand_scale_l)  # 各 50% 概率二选一
为什么不直接 $U(0.5,2)$？因为那样大量样本会落在 1 附近（几乎没扰动），等于"白随机"。双峰方案保证一半样本明确"偏软"、一半明确"偏硬"，强迫策略同时见识软硬两个极端，鲁棒性更强。形式上它在 $[0.5,1]$ 与 $[1,2]$ 两段上各占一半概率密度。

四、随机外力：冷不丁推一把

为了让策略抗扰动，每步以概率 $p=0.25$ 给物体施加一记随机力，且力会随时间指数衰减：

$$F \leftarrow F \cdot \rho^{\,\Delta t / \tau_d}, \qquad F_{\text{new}} \sim \mathcal{N}(0,1)\cdot m \cdot \kappa \ \ (\text{以概率 } p).$$
符号表 · 随机外力
符号含义（cfg）
$\rho$衰减底数 force_decay = 0.9。
$\tau_d$衰减区间 force_decay_interval = 0.08 s。
$\kappa$力的强度 force_scale = 2。
$m$物体质量（力按质量缩放，保证不同质量受扰相当）。
$p$每步施力概率 random_force_prob_scalar = 0.25。

五、重力课程：从月球到地球

一上来就用地球重力，物体很容易掉，策略学不动。于是用"课程学习"：开局重力小得像在月球（−0.05），物体几乎飘着，特别好转；等策略练到几乎没人掉物体了，就悄悄把重力调大一点点，再练……如此逐步加难，直到接近地球重力（上限 10）。先易后难，稳步进阶。

    g = current_gravity_magnitude()

本章小结。 域随机化让策略见识千万种世界（质量/质心/PD/外力/尺寸/噪声），这些随机量同时充当教师的特权信息；PD 用双峰采样逼出软硬极端；外力随机施加并指数衰减；重力课程先易后难、踩着策略进步逐步加难。至此九大主题的原理全部讲完——最后一章把它们串成端到端的实操流程。

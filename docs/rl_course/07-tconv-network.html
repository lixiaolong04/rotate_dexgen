CHAPTER 07 · 钻进网络内部

TConv 与 ActorCritic 网络结构

一维时序卷积怎么把 30 帧历史"嚼"成 8 个数？以及教师-学生共用的那张网到底长什么样。

代码详解。 ActorCritic 与 ProprioAdaptTConv 源码走读见 Part B 第 21 章。

一、为什么用"时序卷积"读历史

30 帧历史像一段 30 秒的小视频。要从中看出"这个东西重不重、滑不滑"，关键是动态模式——比如"我一推它就晃，说明轻"。
一维卷积就是一个"滑动的小窗口"：它每次盯着相邻几帧，提取一个局部特征，然后滑过整段历史。它天然擅长捕捉这种随时间变化的局部规律，且参数比"把 30 帧拍平喂给大 MLP"少得多。

二、一维卷积的数学定义

给定输入序列 $x$（$C_{\text{in}}$ 个通道、长度 $L$）和卷积核 $W$，输出第 $c$ 通道、第 $t$ 个位置为：

$$y[c,\,t] \;=\; b_c \;+\; \sum_{c'=1}^{C_{\text{in}}}\;\sum_{k=0}^{K-1} W[c,\,c',\,k]\;\cdot\; x[c',\; t\cdot s + k].$$
符号表 · 一维卷积
符号含义
$K$卷积核长度（kernel size）。本项目三层分别为 9、5、5。
$s$步幅（stride），窗口每次滑动几格。第一层 s=2，后两层 s=1。
$C_{\text{in}},C_{\text{out}}$输入/输出通道数。这里两者都 = 单帧维度（62）。
$b_c$第 $c$ 个输出通道的偏置。
$W[c,c',k]$可学习权重：把"输入通道 $c'$ 在窗口内第 $k$ 帧"映射到"输出通道 $c$"。

输出长度由这个公式决定（无 padding）：

$$L_{\text{out}} \;=\; \left\lfloor \frac{L_{\text{in}} - K}{s} \right\rfloor + 1.$$

三、ProprioAdaptTConv 逐层拆解

models.py · ProprioAdaptTConv 
self.channel_transform = nn.Sequential(           # 逐帧 MLP（不混时间）
    nn.Linear(frame_shape, frame_shape), nn.ReLU(),
    nn.Linear(frame_shape, frame_shape), nn.ReLU())
self.temporal_aggregation = nn.Sequential(        # 三层时序卷积（混时间）
    nn.Conv1d(frame_shape, frame_shape, (9,), stride=(2,)), nn.ReLU(),
    nn.Conv1d(frame_shape, frame_shape, (5,), stride=(1,)), nn.ReLU(),
    nn.Conv1d(frame_shape, frame_shape, (5,), stride=(1,)), nn.ReLU())
self.low_dim_proj = nn.Linear(frame_shape * 3, 8) # 拍平 → 8 维隐变量

def forward(self, x):                 # x: (N, 30, frame_shape)
    x = self.channel_transform(x)     # (N, 30, frame_shape)
    x = x.permute((0, 2, 1))          # (N, frame_shape, 30)  把"时间"放到卷积维
    x = self.temporal_aggregation(x)  # (N, frame_shape, 3)
    x = self.low_dim_proj(x.flatten(1))  # (N, 8)
    return x

关键的维度演变（frame_shape = 观测维 / 3 = 186 / 3 = 62）：

步骤张量形状 (通道 × 时间长度)怎么算出来的
输入历史62 × 3030 帧，每帧 62 维
逐帧 MLP 后62 × 30只在每帧内变换，时间长度不变
Conv1d(K=9, s=2)62 × 11⌊(30−9)/2⌋+1 = 10+1 = 11
Conv1d(K=5, s=1)62 × 7⌊(11−5)/1⌋+1 = 7
Conv1d(K=5, s=1)62 × 3⌊(7−5)/1⌋+1 = 3
拍平 + 线性投影8Linear(62×3=186 → 8)
三步走的设计意图。 ① 逐帧 MLP 先把每一帧的原始信号"提纯"成更好的特征（通道变换，不碰时间）；② 三层卷积逐步把 30 帧的时间长度压到 3，同时让每个输出"看见"越来越长的历史（感受野扩大）；③ 最后拍平投影成 8 维隐变量 ẑ。整体就是"把一段动态历史，浓缩成一个对物理属性的猜测"。

四、ActorCritic 全貌

教师和学生共用同一张网，区别只在隐变量 z 从哪条路来（第 06 章）。整体由这几块拼成：

models.py · MLP（基础积木） 
class MLP(nn.Module):           # 一串 Linear + ELU
    def __init__(self, units, input_size):
        layers = []
        for output_size in units:
            layers += [nn.Linear(input_size, output_size), nn.ELU()]
            input_size = output_size
        self.mlp = nn.Sequential(*layers)

五、参数初始化的小心思

models.py · ActorCritic.__init__ 
for m in self.modules():
    if isinstance(m, nn.Conv1d):
        fan_out = m.kernel_size[0] * m.out_channels
        m.weight.data.normal_(mean=0.0, std=np.sqrt(2.0 / fan_out))  # He 初始化（配 ReLU）
        if m.bias is not None: nn.init.zeros_(m.bias)
    if isinstance(m, nn.Linear):
        if m.bias is not None: nn.init.zeros_(m.bias)
nn.init.constant_(self.sigma, 0)    # logσ=0 → σ=1，初始充分探索
  • 卷积用 He（Kaiming）初始化 $\mathcal N(0,\, 2/\text{fan\_out})$：方差里的因子 2 专为 ReLU 设计（ReLU 砍掉一半激活，乘 2 补偿），让信号在深层不爆炸也不消失。
  • 偏置全置零：标准做法，避免初始偏好。
  • $\sigma$ 初始化为 0（即 $\log\sigma=0,\ \sigma=1$）：训练初期探索拉满。
本章小结。 TConv 用三层一维卷积把 30 帧历史按 ⌊(L−K)/s⌋+1 逐步压成 62×3，再投影到 8 维 ẑ。Actor-Critic 由 MLP 积木搭成：主干吃 [obs∥z]=194 维，分出 mu(21) 与 value(1) 两个头，σ 是全局参数。卷积用 He 初始化配 ReLU。接下来两章是两个重要的"配角"：在线归一化与域随机化。
